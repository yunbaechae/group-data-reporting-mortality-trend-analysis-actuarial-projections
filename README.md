# Group Data Reporting and Mortality Trend Analysis for Actuarial Projections

ACST3059 Actuarial Modelling Group Case Study (2023)

Group project emphasized data reporting and visualization of Australian mortality trends for actuarial projections. Focused on reproducible trend analysis, curve reporting, and structured group documentation.

## Key Tasks
- Collaboratively analysed mortality data and trends  
- Generated mortality curves and projection reports  
- Documented actuarial implications for product design  

## Skills Demonstrated
- Group data reporting and visualization workflows  
- Mortality trend analysis and actuarial projections  
- Reproducible documentation and stakeholder communication
